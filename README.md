## Installation
### Bot Install Link
https://discord.com/oauth2/authorize?client_id=1554486171466338354

### Instructions
#### Daily Notifications
Run `/frontlines setup` on the channel that you want the bot to post the daily map rotation. Make sure it has access to view and send messages to the channel. Optionally, giving it delete permissions over its own messages lets it clean up its previous notification.

Run `/frontlines disable` to stop the daily posts

#### Manual
Run `/frontlines current` to manually trigger the bot and show the current map rotation.
